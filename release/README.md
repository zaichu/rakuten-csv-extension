# リリース成果物

このフォルダには、`main` の最新コミットから生成した配布ZIPだけを置きます。

- `rakuten-csv-extension-v<version>.zip`: Chromeへ読み込む拡張機能パッケージ
- `chrome-web-store-assets-v<version>.zip`: Chrome Web Store掲載時に使う素材一式

画像の編集元は [`../assets/chrome-web-store/`](../assets/chrome-web-store/) に置きます。
同フォルダの `store-icon-128.png` は、ストア掲載と拡張機能本体で共通利用します。
