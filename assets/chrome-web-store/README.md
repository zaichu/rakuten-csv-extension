# Chrome Web Store掲載素材

Chrome Web Storeのストア掲載で使う素材です。`store-icon-128.png` はストア掲載と
拡張機能本体の両方で使う唯一のアイコン正本です。

## 配置

- `store-icon-128.png`: ストア掲載と拡張機能本体で共通利用するアイコン正本（128x128 PNG）
- `screenshots/`: 掲載用スクリーンショット（1280x800 JPEG、アルファなし）
- `promotional/`: 小型プロモーションタイルとマーキータイル（JPEG、アルファなし）

掲載素材を更新したら、確認用のZIPを `release/` に生成します。`release/` には
編集元を置かず、配布物だけを置いてください。
